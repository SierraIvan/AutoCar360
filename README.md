# AutoCar360

TFG Desarrllo de Aplicaciones Multiplataforma
Iván Sierra Perez

Este proyecto consiste en un gestor de flota de vehículos que permite registrar las revisiones y mantenimientos realizados a cada unidad. Con esta herramienta podrás llevar un control detallado del historial de servicios, lo que facilitará una mejor gestión y te ayudará a maximizar el rendimiento de tus vehículos.

Este proyecto fue desarrollado utilizando el patrón de arquitectura MVC (Modelo-Vista-Controlador) y una base de datos en SQL Server. El objetivo principal es familiarizarme con estas herramientas, así como fortalecer mis conocimientos en el desarrollo de aplicaciones estructuradas y en la gestión de bases de datos relacionales.
